# Abhijith N T – Portfolio

Personal portfolio website: https://abhint.is-a.dev/

## About

Minimal, fast, and accessible portfolio showcasing my work as a Senior Executive at Bajaj Finance and my interests in programming.

## Tech Stack

- **HTML5:** Semantic, accessible markup
- **CSS3:** Responsive design with dark/light theme support
- **JavaScript:** Vanilla, zero-dependency (GitHub API integration)
- **Hosting:** GitHub Pages

## Performance

- **Initial load:** ~15 KB (HTML + inlined CSS)
- **Zero external dependencies:** No jQuery, Font Awesome, or frameworks
- **Dynamic content:** GitHub projects loaded asynchronously
- **Accessibility:** WCAG 2.1 AA compliant
- **SEO:** Semantic HTML with proper meta tags

## Development

No build process required. Edit files directly and push to deploy.

### Files

- `index.html` – Main page with inlined styles
- `robots.txt` – Search engine directives
- `sitemap.xml` – Site structure for indexing
- `README.md` – This file
